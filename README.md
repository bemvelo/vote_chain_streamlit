# VoteChain - Blockchain Voting System

VoteChain is a secure blockchain-based, distributed voting web app system built with Python and Streamlit applying
Blockchain concepts under Parallel & Distributed
Computing. Implemented with Python, Streamlit
and multithreading using Hash and Block structures
to record immutable transactions, ensuring
transparency, scalability, and real‐time performance analysis enabling data driven decision making.

#System Architecture

The application implements a simplified blockchain model including:

##Block Structure

Index,Timestamp,Vote Data,Previous Hash,Current Hash

##Blockchain Ledger

Sequential block linking,Hash validation,Immutable record storage
